 **Credit Risk Analysis Dashboard**

 Overview
   This project analyzes customer credit data to identify delinquency patterns and assess key risk factors using Power BI.

 key Insights
   - High credit utilization increases default risk
   - Missed payments strongly correlate with delinquency
   - Poor payment behavior leads to higher risk levels

 Tools Used
   - Power BI
   - Excel

 Dashboard Features
   - KPI cards (total customers, default rate ,etc.)
   - risk segmentation (low, medium, high)
   - visual analysis of payment behavior
   - Analysis based on employment status

 Key Work Done:
- cleaned and prepared credit dataset
- built interactive dashboard in power bi
- identified high-risk customer segments
- derived actionable business insights

 Conclusion
   This dashboard helps businesses identify high-risk customers and supports better decision- making in credit risk management.
