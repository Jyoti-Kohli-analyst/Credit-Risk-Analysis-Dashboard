# Credit Risk Analysis Dashboard

## Project Overview 
   This project analyzes customer credit data to identify delinquency patterns and key risk factors.

## key Insight
   - High credit utilization increases default risk
   - Missed payments strongly correlate with delinquency
   - Poor payment behavior leads to higher risk levels

## Tools Used 
   - Power BI
   - Excel

## Dashboard Features
   - KPI cards (total customers, default rate ,etc.)
   - risk segmentation (low, medium, high)
   - visual analysis of payment behavior and employment status 

## Conclusion
   This dashboard helps businesses identify high-risk customers and improve decision- making in credit risk management.
